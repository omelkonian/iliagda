# Iliagda

A machine-checked formalisation of the Iliad's prosody in Agda.

Read it at [omelkonian.github.io/iliagda](https://omelkonian.github.io/iliagda/).

View the agda code online [here](https://omelkonian.github.io/iliagda/agda/Iliagda.html).

The formalisation follows Pharr's [*Homeric Greek*](https://www.bibletranslation.ws/down/Pharr_Homeric_Greek.pdf).
